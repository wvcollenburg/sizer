The SC// Infrastructure Sizer turns a description of an existing environment (usually an assessment export from Live Optics, RVTools or Nutanix Collector) into ranked SC//HyperCore cluster recommendations, with growth, redundancy and licensing already accounted for. It then helps you compare options, check a partner quote (BOM) against the Scale Computing hardware compatibility list (HCL), and produce a proposal document.

Signing in

An account is required for everything in the sizer. When you are signed out, the sign-in dialog is always shown.

{{ m.shot("signin", "The sign-in dialog") }}
  • Enter your work email and password and choose {{ m.ui("Sign in") }}.
  • A wrong email and a wrong password give the same message, Invalid email or password, so the form cannot be used to find out who has an account.
  • If your address has not been verified yet, the dialog offers {{ m.ui("Resend verification email") }}.

Creating an account

Choose the {{ m.ui("Sign up") }} tab.

{{ m.shot("signup", "Sign up: the password checklist turns green as each rule is met") }}
  • Your name (optional) is used as Prepared by on new projects. You can change it later by clicking your name in the header.
  • Work email must be on your organisation's own domain. Addresses at public providers (Gmail, Outlook and the like) are refused, because your email domain decides which organisation (tenant) you belong to.
  • Password: at least 10 characters, with an uppercase letter, a lowercase letter, a number and a special character. The checklist under the fields shows which rules are met.
  • Tick I have read and accept the Privacy Policy (required). The product-update emails checkbox is optional and never pre-ticked.

The first person to sign up from a domain automatically becomes that organisation's tenant admin (see For tenant admins). Everyone after that is a regular user.

When email verification is switched on, you get a message with a verification link. The link is valid for 24 hours. You cannot sign in until you have clicked it.

Forgotten password

  1. Type your email address in the sign-in dialog.
  2. Choose {{ m.ui("Forgot password?") }}. You always get the same confirmation, whether or not the address has an account.
  3. Open the link in the email (valid for 2 hours) and set a new password. The same password rules apply.
{% call m.note() %}Password reset and verification emails only work when the sizer's mail server has been configured. If no email arrives, ask your tenant admin or your Scale Computing contact.{% endcall %}

How the pieces fit together

Everything you size lives in a project, normally one per customer or opportunity. A project holds any number of sizings. A sizing is one workload (for example one source cluster), sized into one recommended SC//HyperCore cluster. A typical workflow:

  1. Create a project for the customer.
  2. Add a sizing and import the customer's assessment export. If the export contains several clusters, the sizer can create one sizing per cluster.
  3. Review the environment and the VMs, adjust the sizing options, and pick a recommendation.
  4. Optionally add alternatives (for example all-flash as well as hybrid), a DR target, and a BOM check of the partner's quote.
  5. Compare the options and export a proposal.
