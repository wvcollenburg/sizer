Proposal documents are made on the project page, with {{ m.ui("Exports") }}. One document can hold several sizings: the whole estate, or one solution set.

Making an export

  1. Choose {{ m.ui("Exports") }}, then {{ m.ui("Individual sizings") }} or {{ m.ui("Tag groups") }}. With tag groups, every sizing that carries one of the chosen tags is included, in project order.
  2. Tick what to include.
  3. Choose the format:
    • PDF document: the full proposal.
    • PDF slides: the same content as a presentation.
      • {% if scale %}
    • Word and PowerPoint: editable versions of the two. Staff Only Scale Computing accounts and super admins can make these. Partners who pick them get the message The editable PowerPoint and Word files are available to Scale Computing users only.
      • {% else %}
    • Word and PowerPoint are listed too, but the editable files are reserved for Scale Computing staff. Choosing them shows a message asking you to use a PDF. Ask your Scale Computing contact if you need an editable version.
      • {% endif %}
  4. Tick {{ m.ui("Email me when ready") }} if you do not want to wait.
  5. {{ m.ui("Export") }}. The document is built in the background, and you are taken back to the first step.

Downloads

The first step of the dialog lists your recent exports of this project. Each one shows Generating… while it is being built, then {{ m.ui("Download") }}. A download is kept for 24 hours. After that it says it has expired: make it again when you need it. A failed export shows Failed. Hover over it for the reason. The badge on the {{ m.ui("Exports") }} button counts downloads that are ready.

{{ m.shot("export-downloads", "The Downloads list, with an export still being built") }}

What is in the document

  • It is written in the project's export language (see Project details), whatever language the sizer is in. The customer, Prepared by and the project name come from the project details.
  • Each sizing describes its selected recommendation, or the quoted hardware when Exports as is set: configuration, capacity and utilization, growth, licensing, the network diagram, and the replication between the sizings.
  • A sizing with no saved result is left out of the document, and the export says which ones were skipped. Size and save them first.
  • One document holds at most 50 sections (one per cluster). For a larger selection the sizer asks you to export in parts.
