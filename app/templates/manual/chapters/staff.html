Accounts on the scalecomputing.com domain are Scale Computing accounts. They carry a blue Scale Computing badge. Super admins have all of the features below as well. Everything else in the sizer works for you exactly as it does for partners, so the earlier chapters apply.

{{ m.shot("header-staff", "A Scale Computing account's header", "scale") }}

Opening a partner's work by code

Partners can only open their own organisation's work. Scale Computing accounts can open any organisation's project or sizing with its 12-digit share code. That is how you help a partner: ask for the project code shown on their project page.

  • A project: {{ m.ui("Open by code") }} on the Projects screen. The project is added to your project list, marked Shared, and stays there.
  • A single sizing: {{ m.ui("My Sizings") }} → type the code in Enter 12-digit code → {{ m.ui("Retrieve") }}. It opens straight away and is listed under My Sizings with the source By code. Removing it from your list only removes your link, not the partner's sizing.
{{ m.shot("staff-my-sizings", "My Sizings with the retrieve-by-code box", "scale") }}

A partner's project is always read-only for you. You can look at every sizing, recommendation, comparison and BOM check, but to change something use Copy to mine on the row. The copy goes into a project of your own.

{{ m.shot("staff-shared-project", "A partner's project opened by code: read-only, with Copy to mine", "scale") }} {% call m.note() %}Sizings of an organisation that has been blocked (see Tenants) cannot be retrieved.{% endcall %}

Your colleagues' work

For Scale Computing accounts, My Organization in My Sizings, and Also show my colleagues' projects on the Projects screen, cover every Scale Computing user.

Editable exports

Only Scale Computing accounts and super admins can export Word and PowerPoint files. Partners are only offered the two PDF formats. When a partner needs an editable version, open their project by code, copy the sizings you need into a project of your own, and export from there.

Salesforce link

Project {{ m.ui("Details") }} has an extra field for you: Salesforce opportunity link. It accepts salesforce.com and force.com addresses. Once set, the project header shows an {{ m.ui("Opportunity") }} link. Partners never see this field or the link, not even on a project they share with you.
